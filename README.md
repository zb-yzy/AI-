7B 多模态人脸与文本融合情感识别系统

一、项目简介

本项目面向多模态情感识别任务，融合人脸图像、影评文本双模态完成精细化情感分类。项目引入CBAM、Swin、Transformer等多种注意力机制优化特征提取，结合样本均衡、迁移学习、多阶段模态融合等改进方案提升模型泛化能力。实验在FER、RAF、自制电影封面、Emotic多套数据集完成验证，同时拓展摄像头实时识别、视频情感分析拓展任务。整套代码集成训练、预测、评估一体化流程

&#x20;四、数据集

&#x20;数据集说明

1\. FER、RAF：公开人脸表情数据集，ALL文件夹存放二者合并联合数据集；

2\. movie：自制电影封面人脸专用数据集；

3\. Emotic：连续情感预测公开数据集；

4\. 影评数据集：适配BERT文本分支训练的评论语料。



存放规范

全部数据集统一放置在项目data目录；视频分析任务所需视频文件放入data/video文件夹。



&#x20;预处理代码提示

data-utils文件夹包含数据爬取、人脸截取预处理代码，该模块适配云GPU环境，本地移植改动成本高，部分流程依赖人工标注，仅作为数据处理思路参考，复现实验建议直接使用处理完成的数据集。



&#x20;五、运行方法

项目主脚本为train-test.py，通过脚本顶部CONTINUE-EPOCH参数控制运行次数（已经设置成了实验值，直接运行即可）：



若仅加载已有权重评估：将CONTINUE-EPOCH设置为0

python train-test.py



操作注意事项

1\. 全新从头训练前，需手动删除results目录对应历史文件夹，避免旧缓存干扰；

2\. 1-ALL.py训练产出的权重为后续迁移学习预训练基础模型，需优先完成训练；

3\. 细分任务脚本释义：

序号1\~4对应四项基础任务；movie.py电影人脸训练、review.py评论文本训练；blend.py多模态融合、balance.py样本均衡、move.py迁移训练；mid.py/late.py分别实现中期、晚期融合；attention.py实现注意力融合；可选注意力模块包含CBAM、Swin窗口、移动Swin窗口、Transformer。

4\. 视频/摄像头任务：视频放入data/video，修改代码内文件名完成单视频推理；camera1.py、camera-adjusted.py分别为未添加/添加滤波窗口的实时人脸识别，配套自监督脚本实现视频情感分析。
